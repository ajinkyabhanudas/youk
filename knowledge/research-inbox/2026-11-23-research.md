## Off-Critical-Path Compaction Trigger

**Source:** https://www.preprints.org/manuscript/202611.0780
**Relevant to:** compact_context
**Pattern:** CompactionBench's APEC method prepares a compaction summary off the critical
path at ~70-75% token budget rather than waiting until the context window is full.
Reactive compaction (triggered at the limit) forces the model to summarize under pressure,
when the context is already saturated with stale tokens. APEC pre-builds the brief while
the session still has headroom, so when the host triggers compaction the summary is ready
rather than generated in-band.

## Response Verbosity Enum for Token Control

**Source:** https://www.anthropic.com/engineering/writing-tools-for-agents
**Relevant to:** compact_context
**Pattern:** Anthropic's tool-writing guide recommends adding a `verbosity: "concise" |
"detailed"` parameter to MCP tools. Concise mode surfaces the same information in ~1/3
the tokens. The agent selects verbosity based on remaining context budget — a natural
companion to compact_context's tier tagging.

## Sub-agent Distilled Summary Ceiling

**Source:** https://www.anthropic.com/engineering/multi-agent-research-system
**Relevant to:** skill:orchestrate
**Pattern:** In Anthropic's multi-agent research system, sub-agents return 1,000–2,000
token distilled summaries to the lead agent; full detail stays isolated within the
sub-agent's context. The lead agent synthesizes summaries, never raw outputs. Token
usage explained 80% of performance variance across runs — keeping the lead agent's
context lean was the highest-leverage intervention.
